<h1>Flappy Bird Game </h1>

<h2>Overview</h2>
This is a simple Flappy Bird game developed using Java Swing. The objective of the game is to guide the bird through gaps between pipes by pressing the spacebar to make it fly. Points are earned every time the bird passes through a pair of pipes. The game ends when the bird touches any pipe.

<h2>Features</h2>
<b>Bird Movement:</b>  The bird moves upward when the spacebar is pressed and falls due to gravity when not pressed.<br>
<b>Pipes:</b> Pipes move from right to left, and a new set of pipes is generated at regular intervals.<br>
<b>Collision Detection:</b> The game detects if the bird hits a pipe or the ground.<br>
<b>Score System:</b> Points are awarded each time the bird passes through the pipes.<br>
 The game ends when the bird collides with a pipe, and the final score is displayed.

<h1>Controls</h1>
<b>Spacebar:</b> Flap the bird upward to avoid pipes.

<h1>How to Run</h1>
Clone or download the project.<br>
Open the project in your favorite Java IDE (such as IntelliJ IDEA or Eclipse).<br>
Run the main Java file to start the game.
<h1>Gameplay</h1>

Use the spacebar to control the bird's flight.<br>
Avoid colliding with the pipes.<br>
Earn points by passing through the gap between the pipes.<br>
Once you hit a pipe, the game will end, and your score will be displayed.

<h1>Technologies Used</h1>
Java<br>
Java Swing for GUI components and game interface.
